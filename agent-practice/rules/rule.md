# 共通ルール

## 記述
- 短い単語・文で書く
- 箇条書きで書く

## 用語
- `rules/agent-glossary.md` の用語を使う
- 未登録の用語は登録してから使う

## センシティブなデータ
- 禁止: 外部に送らない
- 対象:
  - パスワード、ハッシュ、セッション ID、秘密鍵
  - 環境変数の値
  - 本番データ、個人情報
  - 社内のホスト名、IP アドレス、ファイルパス
- 外部: Web 検索、Web の取得、外部サービス
- ログ、エラーメッセージ: 対象を含むものとして扱う
- エラーメッセージの検索: 対象を除去・一般化してから行う。できなければ検索しない
- エージェントに読ませない: 本番環境の秘密情報、データ、ログ、バックアップ
  - 理由: 読んだ内容は Claude の API に送信される
- テスト、試行環境: ダミーのデータのみ使う
- 本番環境の障害の解析: 開発者が対象を除去してから渡す

## コード生成・テスト
- 実施条件: 開発者の明示的な指示
- 実行環境の選択肢:
  - Claude のクラウド環境
  - GitHub の CI
  - ローカル環境
- 実施前: 実行環境を問い合わせる
- 実施先: 指示された実行環境のみ

## git
- commit、push: 開発者のみ。エージェントは行わない

## コードの保存先
```
backend/
  app/
    domain/<z>/        # domain
    api/               # api
    persistence/       # persistence
    auth/              # auth
  tests/
    domain/  api/  persistence/  auth/
  migrations/          # persistence
  openapi.json         # api。生成物
frontend/
  src/                 # frontend
    api/generated/     # frontend。生成物
  tests/               # frontend
e2e/                   # E2E テスト
scripts/               # ops
```
- Python のフォルダ名: `<z>` のケバブケースをスネークケースに変える

## 軽微な未決事項の形式
- 保存先: `<入力文書>.todo.md`
```markdown
- TODO-1
  - 内容:
  - 仮の判断:
  - 一般的な対応:
  - 開発者に求める決定:
  - 影響する箇所:
```

## 問い合わせの下書きの形式
- 保存先: `<入力文書>.inquiry.md`
- ID: 発行時に Coordinator が追記
```markdown
- 対象: 入力文書へのリンク、該当箇所
- 問題: 矛盾 / 一意に決められない / 実行できない
- 内容:
- 選択肢と推奨:
- 止めている作業:
```

## 開発者への問い合わせ
- 問い合わせ元: 開発者対話型のみ
- ワーカー型: 親エージェントに返す
- ID: `Q-1` 形式の連番
- ID の再利用: 禁止
- 別ファイルの参照: 相対パスのリンクを付ける

## オープンな問い合わせ
- 保存先: `.tmp/open-queries.md`
- 発行時: 追記
- 解決時: 状態を「解決済み」に更新
- 開始時: 未解決を提示

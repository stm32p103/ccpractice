# /speckit.specify 入力(feature 007: notification)

## 入力

```
# 機能: 通知 — ジョブ完了の通知

## 背景と目的
ジョブが終了したとき、提出者に通知を届ける。コアが発行するドメインイベント(ジョブ完了)を受け取って送信する、独立した部品。
送信先の種類(メール、チャット)は差し替え可能にする。

## 要件
- FR-1 ジョブ完了イベント(成功/失敗/中断)を受けて、提出者に通知する。
- FR-2 通知先の手段(メール、Teams 等)は、ポート(Notifier)のアダプタとして追加できる。
- FR-3 提出者の通知先の決め方(連絡先の取得元)は、設定で定義する。コアは連絡先を持たない。
- FR-4 通知に失敗した場合は、再送する(上限と間隔は設定)。上限を超えたら失敗として記録し、管理者が確認できる。
- FR-5 通知はコアの状態に影響しない。通知が失敗してもジョブの結果は失われない。
- FR-6 同じイベントに対して通知が重複して送られない(または重複しても影響がない)。
- FR-7 通知の内容は、ジョブの状態、結果の要約、WebUI の詳細ページへのリンクを含む。
- FR-8(機密保護)通知に含めるのは FR-7 の項目に限る(書き出し台帳 E10)。ログの本文、成果物の中身、ランナー PC の情報を含めない。

## 受け入れ基準(例)
- 偽の送信先で、完了イベントから通知が生成され、失敗時に再送される。
- 送信先を差し替えても、コアは変更されない。

## スコープ外
- ジョブの管理、WebUI のお知らせ表示

## 未確定事項
- [NEEDS CLARIFICATION] 通知先の種類(メール/Teams/Slack)と、連絡先の取得元
- [NEEDS CLARIFICATION] 管理者向けの通知(異常の検知)の要否
```

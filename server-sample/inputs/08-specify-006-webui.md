# /speckit.specify 入力(feature 006: webui)

## 入力

```
# 機能: WebUI — ジョブとランナーの管理画面

## 背景と目的
利用者がジョブの状態と結果を確認し、管理者がキューとランナーを管理する、イントラネット向けの画面を作る。
コア API の公開契約だけを使うクライアントであり、コアの内部や GitHub を直接知らない。
用途が変わっても、画面の中核を作り替えずに使えること。

## ユビキタス言語
- 画面の利用者: 一般の利用者(利用者ロール)、管理者(管理者ロール)。ロールの決定は認証アダプタ(別 feature)が行う。

## 要件
- FR-1 ログインは、認証アダプタ(ポート)経由で行う。最初の実装は GitHub(feature 005)。
- FR-2 利用者は、自分のジョブの一覧(絞り込み・ページ分割)と、詳細(状態、結果、ログ、成果物)を確認できる。実行中の状態とログは自動で更新される。
- FR-3 利用者は、自分の待機中のジョブを取り消せ、終了したジョブをやり直せる。
- FR-4 管理者は、全ジョブとキュー全体(順序つき)を確認できる。
- FR-5 管理者は、待機中のジョブの優先度を変更し、順序を入れ替え、割り込み指定ができる。
- FR-6 管理者は、実行中のジョブを強制中断できる。操作前に確認を求め、理由を入力する。
- FR-7 管理者は、ランナーの一覧と状態(online/offline/maintenance、実行中のジョブ)を確認し、無効化/有効化できる。
- FR-8 管理者は、監査ログを検索・閲覧できる。
- FR-9 利用者に許可されていない操作は、表示されない(または無効)。最終的な認可は API 側で判定される。
- FR-10 用途固有の表示(ジョブの payload の見せ方、結果の項目)は、設定または用途ごとの部品で差し替えられ、画面の中核は用途の語を含まない。
- FR-11 イントラネット内のブラウザから使える。インターネットへの接続や外部の配信資産(CDN 等)に依存しない。
- FR-12(機密保護)ブラウザから、コア API 以外の宛先への通信を行わない。テレメトリ・解析・外部フォント・外部スクリプトを使わない(書き出し台帳 E11)。
- FR-13 画面でログや payload を表示するとき、内容は無害化して表示する(スクリプトとして実行されない)。
- FR-15(技術方針)UI 部品は Fluent UI(Fluent UI React v9)を使い、テーマ(ライト/ダーク)も Fluent の機構で扱う。Fluent にない部品のみ独自に作る。
  フォント・アイコン・スタイルは、外部の配信資産に依存せず、ビルド成果物に同梱する(FR-12 と整合)。
- FR-14(技術方針)実装は TypeScript + React とし、Modern Web Guidance に従う。アクセシビリティ(キーボード操作、スクリーンリーダー)、現在の Web 標準の API、性能の基準を満たす。

## 受け入れ基準(例)
- 偽の認証基盤とコア API だけで、全画面を操作できる(GitHub なしで)。
- 利用者ロールでは、管理操作(優先度変更・強制中断)が表示されず、API を直接叩いても拒否される。
- キューの順序入れ替えが、他の管理者の画面にも反映される。

## スコープ外
- コアの機能、認証の実装(GitHub 固有部分)
- 通知の送信

## 未確定事項
- [NEEDS CLARIFICATION] 利用する端末(PC のみ/タブレットも)とレイアウトの方針
- [NEEDS CLARIFICATION] 順序入れ替えの操作(ドラッグ/数値入力)
- [NEEDS CLARIFICATION] 対応ブラウザと画面の言語(日本語のみ/多言語)
```

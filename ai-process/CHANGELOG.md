# 変更履歴

## 0.3.0（2026-11-12）
ai-process の範囲を「自ドメインのエージェント・スキルの育成と、人向けの知識の集約」にとどめ、知識の書式を足した版（AP-D19〜AP-D22）。

- 知識の書式を追加（`docs/knowledge-format.md`）。ドメインのプラグインの `knowledge/` に知識の正本、`public/` に公開用の索引を置く
- 索引の知識一覧を knowledge/ の frontmatter から作るスクリプト（`scripts/build_public_index.py`）と、その自己テストを追加。ドラフトの知識も、ドラフトと明示して載せる
- ドメインのひな形（`templates/domain/`）を追加
- スキルを作るスキルに、スキル（やり方）と知識（事実と経緯）の分け方、知識のため方、チェックリストの項目を追加
- 例や説明文から、扱っている製品や具体的な技術が分かる記載を除き、記号（A・B・C、X・Y・Z）に置き換えた
- 評価の結果: 既存の自己テストと、追加した自己テストが通ることを確認。回帰テストは未実施（スキルを作るスキルは評価ケースの対象外のため）

## 0.2.0（2026-11-07）
初めてリポジトリに入れた版。

- スキルを作るスキル（agent-skill-builder-coach）を追加。ゲートと人の確認の設計（P3b）、評価の共通部と題材固有部、オラクルの強さ、体制の版管理、抜け漏れを防ぐチェックリストを含む
- 評価の仕組みを、共通部（`eval/`）と題材固有部（`eval-cases/equipment-loan/`）に分けた
- B（契約→テスト）を2段階にした: テストケース一覧 →（人の承認）→ テストコード。一覧とコードをスクリプトで突き合わせる（AP-D07, AP-D08）
- A（要件→契約）の確認を、契約から作った表で行うようにした（AP-D09）
- 人が見るものを review.md（表と、機械が挙げた点）にまとめた
- 成果物（result.json）に体制の版とモデル名を記録するようにした
- Copilot 向けの書き出し（`scripts/export_copilot.py`）と、Claude アプリ向けの zip 作成（`scripts/pack_skill.py`）を追加
- 評価の結果: まだ無い（ベースラインは次の作業）

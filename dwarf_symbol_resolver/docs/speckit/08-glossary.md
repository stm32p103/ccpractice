# 用語集

| 用語 | 意味 |
|---|---|
| 左辺値 | モニタ対象の指定。変数、配列の要素、構造体・共用体のメンバ、ビットフィールド、およびそれらの組み合わせ (`st.ar[1].m[4]`)。ポインタを経由するものは含まない |
| ルート変数 | 左辺値の先頭の変数 (`st.ar[1].m[4]` の `st`) |
| スコープ指定 | static 変数を区別するための前置き。`ファイル名::`、`関数名::` |
| AccessPath | 左辺値を「ルート変数 + メンバ/インデックスの並び」で表したもの。入力の形 (文字列など) に依存しない |
| 処理系 | コンパイラとリンカの組み合わせ (arm-none-eabi-gcc、Green Hills など) |
| 処理系の癖 | 標準の DWARF の範囲内での表現の違い、または標準からの逸脱 (ビットフィールドの位置の表し方など) |
| DebugInfoSource | デバッグ情報から型と変数を得る部品 (Protocol)。処理系ごとに実装を差し替える |
| SymbolAddressSource | 変数のアドレスを別の情報源 (ELF シンボル表) から得る部品 (Protocol)。補完と照合に使う |
| フック | `DwarfSource` のメソッドのうち、処理系の癖を吸収するために上書きしてよいもの |
| 正規化 | 処理系ごとの表現を `model.py` の約束 (バイト単位、リトルエンディアン式のビット位置 など) に揃えること |
| 格納単位 | ビットフィールドを読み出す単位。宣言型の幅 (`unsigned int` なら 4 バイト) |
| マスク | 格納単位を読み出してリトルエンディアンで整数にした値のうち、対象のビットを 1 にした値 |
| Encoding | 読み出した値の解釈 (符号付き整数、符号なし整数、浮動小数点、真偽値) |
| Linkage | 変数の結合 (外部結合、ファイル内 static、関数内 static) |
| コメント形式 | コメントの書き方の種類。1 形式 = `comments/formats/` の 1 モジュール |
| parsed (抽出結果) | コメント形式が抽出した項目。Key-Value (`dict[str, str]`) か dataclass。値は加工しない文字列 |
| T | 利用者がコメントから作る情報の型。`build(parsed) -> T` で作る |
| サンプル (`Sample`) | コメント形式が持つ、その形式のコメントの例と期待する parsed。自己テストと衝突確認に使う |
| 衝突 | ある形式の判定用の正規表現が、ほかの形式のサンプルに合致すること。許容しない |
| カタログ | コメント形式の一覧 (`CATALOG.md`、`ALL_FORMATS`)。`dsr-comment-catalog --write` で生成する |
| プローブ | マクロ展開のために作るファイル (`#include` で対象の .c を取り込み、目印付きの左辺値を並べたもの) |
| 正解 (検証での) | 同じ処理系でビルドしたコードから得た `&(lhs)`、`sizeof(lhs)`、ビットフィールドの初期化イメージ |
| バリアント | 同じ処理系の、オプション違いのビルド (DWARF のバージョン違いなど) |
